# OOP Supo Week 2 Homework

Java source for the OOP Supo Week 2 homework.

## Run

Requires JDK 11 or newer. From this directory:

```sh
javac Main.java Player.java Difficulty.java Scoreboard.java HiLoGame.java Sol7.java
java Main
```

The main program runs the Hi-Lo game. `Sol7` is a separate small exercise and can be run with `java Sol7` after compilation.
